# Security review — 2026-11-05 (pre-release)

Scope: all extension code (background, content script, popup, options, welcome), build and CI.
Checklist: OWASP Top 10 (2021) + OWASP Top 10 Client-Side Security Risks, plus browser-extension
threats. Threat model: every web page the reader runs on is hostile. See [SECURITY.md](../SECURITY.md).

## Reviewed, no issue found

| Area                    | Result                                                                                                                                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A03 Injection / DOM XSS | Article HTML sanitized with DOMPurify in the isolated world (page can't tamper with it); titles/bylines rendered as React text; no `eval`/`new Function`; regexes on page text are linear (no ReDoS) |
| A07 Authentication      | No accounts or credentials                                                                                                                                                                           |
| A09 Logging             | Only a font-load warning; no page data or URLs logged                                                                                                                                                |
| A10 SSRF                | Only fetches its own packaged files                                                                                                                                                                  |
| Permissions             | `activeTab`, `scripting`, `storage` only; no host permissions, no always-on content scripts, no `tabs`, no `externally_connectable`                                                                  |
| Storage integrity       | All stored settings re-validated on read (`normalizeSettings`)                                                                                                                                       |
| Third-party origins     | No CDNs, analytics or remote code                                                                                                                                                                    |
| Reverse tabnabbing      | `target` removed from article links; options links use `rel="noreferrer"`                                                                                                                            |

## Accepted / residual risks

- **Page can see that the reader is open** (the host element exists in the page DOM while it's on). Inherent to drawing on a page; nothing is exposed when it's off.
- **Page can cover or remove the reader** (z-index, DOM removal). Annoying, not a data risk.
- **Hashes are unsalted**: someone with access to the browser profile who already suspects a specific URL can confirm it was read. They can't list what was read, or recover tokens in URLs.
- **Closed shadow root is only in store builds** (tests need open). Covered by a manual smoke test of the store build.
